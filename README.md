## 📱 About the App

**Community Day Companion** is a mobile application designed for Fiscal Solutions Community Day, bringing the event schedule, talks, speakers, expert consultations, networking and other event information into one place.

### Technologies

* React Native
* Expo
* TypeScript
* Supabase

---

## 👩‍💻 My Role

I independently developed the hackathon prototype and continued developing the project over the following three months.

My work included **UI/UX, mobile development, database design, authentication, backend integration and implementation of the core application functionality.**
